
# TrafficPulse 🚦

TrafficPulse is a smart traffic monitoring and route planning web application.

## Features

- Live Traffic Map
- Traffic Status
- Route Planner
- Community Traffic Reports
- Traffic Prediction
- User Profile
- Responsive Design

## Technologies Used

- HTML
- CSS
- JavaScript
- Leaflet.js
- OpenStreetMap

## Project Purpose

The purpose of TrafficPulse is to help users understand traffic conditions,
find better routes, and report traffic-related problems.

## Future Scope

- Real-time traffic data
- Dijkstra's Algorithm
- AI-based traffic prediction
- Alternative route recommendation
- Mobile application
